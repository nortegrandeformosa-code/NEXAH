# NEXAH Radio

Sitio de oyente + cabina de operación.

- `index.html` — aire público
- `cabina.html` — piso interno y control de aire

## Capas de audio

1. **Cama** — stream gratuito SomaFM (Indie Pop Rocks / fallback PopTron / house The Trip). Nunca se corta.
2. **Voz** — pisadores y spots encima, con ducking. Un pinchador a la vez.
3. **Ciclo** — 5 a 9 minutos entre pinches. El siguiente espera sí o sí.

Sin autoplay. Eslogan: La radio está siempre en movimiento.
