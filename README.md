# NEXAH Radio — sitio

Landing operativa lista para dominio. Sin autoplay de audio. El video de estudio va muted.

## Stack
HTML estático. GitHub Pages en este repo. También corre en Netlify.

## Subir al dominio
1. Comprar `nexaradio.app` o `nexaradio.net`.
2. Settings → Pages → Custom domain.
3. DNS:
   - A → `185.199.108.153` `185.199.109.153` `185.199.110.153` `185.199.111.153`
   - o CNAME `www` → `nortegrandeformosa-code.github.io`
4. Netlify: arrastrar la carpeta del sitio o `netlify deploy --dir=. --prod`.
